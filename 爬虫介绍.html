Core Features

强大功能一览

从请求伪装到数据清洗，全流程覆盖

🕵

智能反爬

随机 User-Agent 轮换、1~5 秒随机等待、异常自动重定向重试，轻松应对反爬机制。

🔒

Tor 代理

一键启用 Tor 网络代理，隐藏真实 IP，支持通过 Edge 浏览器走 Tor 通道。

🎬

多格式下载

支持文本 (.html)、图片 (.png)、音频 (.mp3)、视频 (.mp4) 四种文件类型下载。

🧹

数据清洗

内置 HTML 标签提取引擎，支持 class/id 筛选，3 种提取模式，自动去重保存。

📝

灵活配置

自定义 Cookie、防盗链 Referer、请求头，全程命令行交互式引导，零配置上手。

📋

日志追踪

按日期自动归档日志，详细记录每次请求状态，方便排查问题与审计。

Workflow

使用流程

简单 10 步，从启动到获取数据

01

启动程序

运行 python src/main.py，显示 ASCII 横幅

02

配置请求头

选择内置 User-Agent 或自定义请求头

03

设置 Cookie & Referer

输入 Cookie 和防盗链信息（可跳过）

04

选择内容类型

文本 / 图片 / 音频 / 视频

05

输入目标 URL

粘贴要爬取的网页地址

06

代理设置

选择是否启用 Tor 代理

07

选择保存目录

弹出文件夹选择对话框

08

命名文件

输入保存文件名

09

执行爬取

自动请求、解析、保存文件

10

数据清洗（可选）

运行 data_cleaning.py 提取 HTML 标签内容
